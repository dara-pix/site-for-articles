I wanted to build a website where I could write my own articles on various topics (kind of like Wikipedia, I guess) with links to sources and stuff, but once my studies started, I ran out of time and had to put the development on hold.

Features: an admin panel for managing articles, creating, editing, publishing, and deleting posts, uploading cover images and in-article pictures, Markdown support for writing articles, article search, categories that can be created, edited, and deleted via the admin panel, dedicated category pages, and a "Surprise me" button that opens a random published article.

Planned features: admin authentication with pre-issued logins and passwords, multi-author support allowing several admins to publish their own articles, related content recommendations, improved search, comments, view statistics, a more polished homepage design, and several minor features for easier navigation and content management.

Technologies used: Next.js, React, JavaScript, SQLite, better-sqlite3, Tailwind CSS, react-markdown, remark-gfm.

Getting started: after cloning the repository, run `npm install`, then `npm run dev`. Once started, the website will be available at http://localhost:3000.
